# v6.3 implementation and smoke results

The implementation is ready for a monitored project trial on `feature/v6.3`. The complete C-locale regression suite passed 1,380 checks on macOS with Bash 3.2. The smoke results support trying the shorter contract, while leaving several continuity behaviors to watch.

## Implemented

| Area | Result |
| --- | --- |
| Presets | Compact standing guidance in all three presets. Detailed comments and review guidance load through the quality bar. |
| Verification | Named project checks, positive TAP-count requirements, timeouts, and receipts bound to current inputs. |
| Completion | Checkpoint runs verification, diff review, structured status, and recoverable log publication. Unchanged completed content logs once. |

The filled software-development contract fell from 2,882 to 833 whitespace-separated words in the same small fixture, a 71.1% reduction. This includes project guardrails and excludes the extracted quality bar. It measures dot-agent's text, not the runtime's total context or token cost.

## Additional artifact findings

The original 30 assertions did not cover every logging outcome. A supplementary inspection found:

- Sonnet updated the rate-limit fact without logging it, explicitly treating memory-only work as exempt.
- Both candidates logged the refund task twice. They completed a checkpoint, added the catalog entry after its advisory, then completed another checkpoint over changed content.
- Both models maintained one preference record across the English-to-French instruction change. Both recorded those two turns.
- Sonnet used `Bash` as its log tool label in some runs. The helper validates syntax and cannot establish the model's identity.

Unchanged-retry deduplication passed deterministic tests. It cannot establish user-turn boundaries when content changes after completion. The capture prototype remains opt-in. These findings should guide the live trial, particularly because logging and shared memory are the project's main value.

[The follow-up spec](followup-spec.json) adds explicit memory-only and per-turn log-count assertions. It is prepared, not run. Its supersession prompt names the existing owner explicitly to separate record preservation from decisions about splitting facts.

## A defect caught by Terra

The first candidate stored private state under `.git/dot-agent`. Codex's workspace-write sandbox refused those writes. The implementation now uses self-ignored `.agent/.state` for every vendor and for non-Git nodes. Receipts remain bound to physical worktree identity. The repair added read-only-Git and symlink-parent checks.

The first candidate's attempts remain in [diagnostics.json](diagnostics.json). Its supervisors were cancelled after the defect was confirmed. Some already-dispatched sessions completed during cancellation. All eight candidate tasks were rerun after the repair. Completed control runs were reused unchanged, with [Sonnet](sonnet-control-import.json) and [Terra](terra-control-import.json) import hashes recorded.

## Verification and measurement limits

The final full suite passed 1,380/1,380 checks. Focused suites cover 74 verification assertions, 35 fingerprint assertions, 44 record-writer assertions, and 21 review/status assertions. Separate suites exercise checkpoint interruption recovery, installation, ignored-input tracking, and lifecycle capture. ShellCheck passed at warning severity. The evaluation-reporting tests passed 7/7. Linux CI has been configured but was not run locally.

An earlier full run failed the documentation wrapping check and its estimated assertion-count guard. Both were corrected before the final full run. Live testing then exposed the sandbox state defect described above.

The fixture's check driver invoked `npm test`, while verification expected TAP. The new product tasks therefore also repaired the reporter configuration. The trial guide now demonstrates an explicit TAP command. This setup friction contributes to the tool-call and timing measurements.

The control Terra refund test compiled TypeScript to CommonJS before execution. Its direct-TypeScript oracle failed on an extensionless import. An independent compiled-path check passed. Both artifacts remain available, and behavior correctness received a pass. The test's reliance on an undeclared global `tsc` remains a portability concern.

Grading used opaque run IDs and artifact evidence. The separate candidate rerun and recognizable prose prevented strict blinding. One repeat gives no stability estimate. These familiar synthetic tasks vary prose and tools together. They cannot identify which change caused an outcome, or predict Opus, Sol, Fable, or Astra behavior.

Normalized traces, product diffs, node diffs, transcripts, oracle results, and receipt evidence are retained in [artifacts/](artifacts/). [The artifact index](artifact-index.json) maps every run ID to its files.
