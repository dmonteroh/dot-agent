# v6.2 release validation — 2026-09-21

This report supersedes `v6.2-release-validation-2026-09-20.md`. That run could not build the historical baseline and produced no paired result. The compatibility, batch-status, arm-label, comment-gate, and migration fixes landed before this run.

## Verdict

V6.2 is ready to publish for the software-development preset scope measured here. Both agents show a positive candidate delta and zero regressions. Assertions that remained mixed within an arm after five repeats stay classified as unstable and support no per-assertion release claim.

## Run design

- Scope: all 19 `arm_variable: corpus` scenarios in `evals/spec.json`.
- Agents: Claude Code 2.1.245 with `claude-sonnet-5` at medium effort, and Codex CLI 0.154.0 with `gpt-5.6-terra` at medium effort.
- Primary repeats: three per assertion and arm.
- Focus repeats: five on every eval containing an unstable primary assertion.
- Timeout: 900 seconds per session.
- Concurrency: two evals per arm.
- Prompt set: `evals/spec.json`. The held-out prompt set was outside this release gate.

Every primary session completed: 114 Claude sessions and 114 Codex sessions, with no void run. The focused runs also completed without voids: 30 Claude sessions and 70 Codex sessions.

The manual review used `triage.py` excerpts without opening `arm-map.json`. The primary runs contained 66 manual records per agent. The focused runs contained 10 Claude manual records and 60 Codex manual records.

## Scope limits

This run measures the software-development preset and the canonical prompt set. It does not validate the academic-research or domain-knowledge presets, the held-out prompt set, generated-index versus manual mode, or a provider without a first-party adapter.

The raw session artifacts remain in system-temporary storage because they contain complete model transcripts and fixture trees. The versioned report records the frozen revisions, run design, computed rollups, manual-grade counts, costs exposed by the CLIs, and every qualifier on the verdict.
